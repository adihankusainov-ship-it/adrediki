# Blackcraft font setup

Put the actual Blackcraft font files in this folder, for example:

- `Blackcraft-Regular.woff2`
- `Blackcraft-Regular.woff`
- `Blackcraft-Regular.ttf`

Then the project CSS will automatically use them.

If you download the font from a site like cdnfonts, keep the same names or update the paths in `styles.css`.
